# Статья HFD–U1

**Название:** Конечновыборочная вариабельность статистики Хигучи и эмпирическое покрытие блочных bootstrap-интервалов для коротких зависимых временных рядов.

**Автор:** Прозорова Кристина Евгеньевна.
**Аффилиация:** Кафедра инженерной кибернетики, НИТУ «МИСИС», Москва, Россия.
**Email:** m2307859@edu.misis.ru.
**Коды:** ГРНТИ 28.23.00; ASJC 1706 (предварительно); OECD не определён.

**Тема:** конечновыборочная оценка статистики Хигучи для стационарных синтетических AR(1)/MA(1)-рядов и эмпирическое покрытие блочных bootstrap-интервалов.

**Результат:** при N=384 ни одна из четырёх блочных конфигураций не достигла покрытия 90% одновременно на всех трёх моделях. Сравнение basic (80%) и диагностического percentile (93%) для M2/N384/MBB32 не является независимой валидацией.

**Ключевые слова:** размерность Хигучи, зависимые временные ряды, блочный bootstrap, доверительные интервалы, Монте-Карло.

**Исходные файлы:** article.tex, article_body_hfd_u1.tex, misisarticle.cls.
