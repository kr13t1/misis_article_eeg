# Эксперименты

В этой папке находятся скрипты пилотного анализа и сравнения признаков.

- `d2_synthetic_validation.py` — проверка чувствительности корреляционного наклона на синтетических сигналах.
- `d2_eeg_stability.py` — анализ влияния параметров оценки D2 на эпохи левой/правой руки по одному GDF-файлу.
- `classification_comparison.py` — exploratory LOSO-сравнение HFD, PSD и PSD+HFD по доступным файлам `A01T.gdf`–`A09T.gdf`.

## Запуск

Из корня репозитория:

```bash
python experiments/d2_synthetic_validation.py
python experiments/d2_eeg_stability.py --gdf "C:/path/to/A01T.gdf"
python experiments/classification_comparison.py --data-dir data/raw
```

Для EEG-скриптов нужен набор BCI Competition IV 2a, скачанный отдельно. Не загружайте GDF-файлы в GitHub. Перед использованием результатов в статье проверьте, что события в локальных файлах распознаются правильно и параметры совпадают с описанным в рукописи протоколом.

## Ограничения

Эти скрипты — исследовательский каркас, а не автоматическая гарантия научно валидной оценки D2. В частности, `d2_eeg_stability.py` оценивает наклоны на нескольких заданных диапазонах радиусов и выводит чувствительность; он не доказывает наличие истинного масштабного плато. `classification_comparison.py` сравнивает простые band-power признаки и HFD; в нём не реализована классификация на основе D2, поскольку предварительный анализ пока не подтвердил устойчивость такого признака.
