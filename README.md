# Исследование фрактальных характеристик ЭЭГ-сигналов для классификации состояний моторного воображания

Репозиторий сопровождает исследование HFD и корреляционной размерности `D2` для анализа ЭЭГ при моторном воображении на наборе BCI Competition IV 2a.

## Статус

Работа находится на исследовательском этапе. Синтетические сигналы и ограниченная часть записи участника A01 используются для проверки реализации и анализа чувствительности оценки `D2`. Эти результаты не являются окончательной оценкой качества классификации. Утверждения об улучшении классификации будут добавлены только после единого сравнения моделей и протокола валидации.

## Структура

- `article.tex` — основной файл LaTeX из шаблона МИСИС. Сохраните его преамбулу и команды шаблона, укажите метаданные статьи и подключите `article_body.tex` в месте основного текста.
- `article_body.tex` — текст разделов статьи.
- `references.bib` — библиографические записи.
- `experiments/` — скрипты анализа и инструкции по воспроизведению.
- `data/` — инструкции по размещению исходных данных; сами данные в репозиторий не включаются.
- `results/` — описание предварительных результатов.
- `figures/` — графики, подготовленные для статьи.

Файлы `misisarticle.cls`, `Makefile`, `LICENSE` и конфигурацию сборки, полученные из шаблона [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex), не заменяйте файлами из другого шаблона.

## Данные

Используется BCI Competition IV 2a: четыре класса моторного воображения (левая рука, правая рука, ноги, язык), 22 EEG-канала, 3 EOG-канала и частота дискретизации 250 Гц. См. официальное описание соревнования: https://www.bbci.de/competition/iv/ . Следуйте условиям распространения исходных данных.

Не загружайте в GitHub исходные GDF-файлы, персональные записи или большие производные датасеты. В репозитории следует хранить код, параметры экспериментов, компактные итоговые таблицы и графики, если это допустимо условиями датасета.

## Среда

Рекомендуется Python 3.10 или новее. Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Файл `requirements.txt` задаёт основной набор библиотек; при проведении итоговых экспериментов необходимо зафиксировать версии реально использованных пакетов и случайных состояний.

## Воспроизводимость

Перед окончательным сравнением следует зафиксировать: временное окно эпохи, фильтр, набор каналов, параметры HFD, задержки и размерности вложения для `D2`, окно Тейлера, диапазон радиусов, классификатор, стратегию разделения участников и метрики. Все трансформации, обучающие параметры которых оцениваются по данным, должны подгоняться только на обучающей части.
