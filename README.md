## Исследование

Изучается статистика Хигучи `T_{N,16}` и покрытие доверительных интервалов для конечновыборочного параметра `θ_{N,16} = E[T_{N,16}]`. Эксперимент выполнен на трёх стационарных синтетических AR(1)/MA(1)-моделях при длинах рядов 384 и 768. Рассмотрены basic-интервалы moving block bootstrap, stationary bootstrap и IID-контроль. Percentile-интервалы сравниваются дополнительно, в диагностическом порядке.

При `N=384` ни одна из четырёх блочных конфигураций не достигла предзаданного порога покрытия ≥90% на всех трёх моделях. Этот результат не является доказательством общей несостоятельности блочного bootstrap или гарантией для реальных ЭЭГ.

Численные результаты прошли независимую проверку сохранённых таблиц; полный Monte Carlo независимо не перезапускался. Для рукописи остаются открытыми вопросы полноты литературного сопоставления и требований конкретного издания.
