# Конечновыборочная вариабельность статистики Хигучи

Методологическая статья о конечновыборочном распределении оценки Хигучи и покрытии блочных bootstrap-интервалов для стационарных зависимых временных рядов.

**Автор:** К. Е. Прозорова — Кафедра инженерной кибернетики, НИТУ «МИСИС».

## Сборка

Установите XeLaTeX и шрифты с поддержкой кириллицы (Liberation Serif либо Times New Roman). Затем:

```bash
make article
```

Результат: `build/article.pdf`. При изменениях `article.tex`, текста или класса GitHub Actions также собирает PDF.

## Исследование

Использованы синтетические стационарные AR(1) и MA(1) временные ряды длиной 384 и 768 наблюдений, а не реальные EEG. Рассмотрены интервалы moving block bootstrap, stationary bootstrap и IID-контроль. Эмпирическое покрытие оценивается относительно конечновыборочного среднего статистики Хигучи. Отдельный анализ percentile-интервалов носит диагностический характер.

Численные результаты прошли аудит исходных таблиц; полный независимый перезапуск Monte Carlo не проводился. Обсуждение ограничено проверенными моделями и не доказывает гарантии для EEG.
